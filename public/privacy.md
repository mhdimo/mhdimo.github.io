# Privacy statement — mhdimo.github.io

Markdown mirror of https://mhdimo.github.io/privacy/ — the HTML page is canonical.

This site (mhdimo.github.io) is a static personal portfolio hosted on GitHub Pages. It is intentionally minimal about data: it does not use cookies, does not run analytics scripts, does not embed advertising, and does not set any tracking identifiers.

## What this site does not do

There are no forms, no user accounts, no comment systems, and no payment flows. Nothing you do on this site is stored by the site owner. The only visitor data that exists is the access log that GitHub's hosting infrastructure records for operational purposes, which the site owner does not process, sell, or use for profiling.

## Third-party requests

To render the projects section, the page makes a browser-side request to the GitHub REST API (api.github.com) for public repository metadata. This request is made by your browser to GitHub, and its privacy terms apply. If that request fails, the page shows static fallback text with no network dependency. Fonts are loaded from Google Fonts; Google's privacy policy applies to those requests.
